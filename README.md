# Hi, I'm Wesley 👋

**Informatics student at Universitas Ciputra Surabaya · Full-stack developer for web and mobile**

I enjoy working in collaborative teams on hands-on projects, where I usually take on the **backend, database design, and core app logic**: REST APIs with Express and Prisma, Laravel web apps, and native apps in Swift and Kotlin. I'm passionate about using systems thinking and solid database architecture to turn real-world workflows, such as restaurant orders, medication schedules, and trip plans, into clean, scalable software that is both functional and easy to maintain. I'm always exploring new frameworks to keep improving how I build.
